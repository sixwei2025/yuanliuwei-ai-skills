
### 例
**输入（虚构）**
```
昨天我加班回家他还在打游戏，我把晚饭热了也没人说谢谢。我希望被看见一点。
```
**输出（实跑 raw，未改写）**
```
他听见你回来了，也没从游戏里抬头；饭热好了，一句谢谢都没有——你想被看见一点，这个希望一点都不过分。

我先把刚才这段拆开，你看是不是这样：

- **事实**：昨天你加班回家，他在打游戏；你热了晚饭，没有人说谢谢。
- **解释**：你心里冒出来的是「他好像觉得这一切理所当然」——这是你的感受和推断，不是已经确认的事实。
- **期待**：你希望被看见一点。

一种看法是：可以试着分清哪些是你能决定的、哪些不是。你能决定的是自己怎么做、要不要开口说；他能不能因此变得主动、会不会改，你决定不了。这不是让你忍着，而是先把力气放在你能动的那一边。

另一种看法是：一直「什么都先想他」，本身可能就藏着期待——你付出的时候，其实是在等一个回应。这不是说你错了，只是这个期待一直没被摆到台面上说过。

接下来你可以自己挑：这周找一次他不打游戏的时机，具体说一句「昨天我热饭没人应，我有点难受」；或者先不做什么，只是把这些委屈说出来、被听见一下。你想选哪个，还是先聊聊就好？
```
